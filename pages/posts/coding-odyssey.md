余习软件开发凡十二载。初二年，专攻 JavaWeb，后专事前端。历岁之间，所治多为后台 Admin 之系统，间涉数据可视化、微信小程序，及 Electron 客户端之营建。

始学 JavaWeb，乃习 SQL；尝躬亲部署，渐识 Tomcat、Nginx、Docker，然仅能循例而用，未探其奥。

前后供职四司，分属金融、交通、水利、医疗诸业。各业业务迥殊，及窥其底层，则大同无异，不外后台管理、数据可视化、小程序之属。久习此类，不复以为难，遂潜心研项目模板。启我门者，[vue-element-admin][vea] 也。余遍阅其源码文档，由是通晓前端工程化之体系。

自是技艺日进，不复囿于页面与模板，思以**代码生代码**。当是时，“低代码”之名未广传，初试 VBA，囿于 Office，乃转以Node.js 屡作尝试。久之方悟，JS 性能有限，非为此类长策。

遂广求他语言而学之：自素熟之 Java 始，继及 Go、Python、C#、C++。较之 JS，其余诸语言文繁句冗，虽规制谨严，读之觉繁。尝欲自创语言，仅存臆想而已。后 Rust 出，所有权、生命周期之说新世所惊，余观之，究其根本，不外指针内存之管，类于 C。自知非天授之才，研习 Rust，屡遭困阻，中道而止。后欲深研 Go、Python，每识基础文法，辄乏恒心，今仅能辨数种语言简易语法。

洎 AI 大兴，虽才不及专门巨擘，借 AI 之力，亦可操诸语言，以成业务之开发。

未几，逢行业震荡，余遭裁撤。待业半载，边觅职边研技艺，收效甚微。虽历多端，常自谓可全栈开发，然心中未敢自许。求事之际，心志怠缓，迁延至今。忆昔求职，数日间辄得聘，今则困顿难言。

久独耽于所好，此番求职挫辱，击余甚深。常自忖：弊在技艺耶？简历耶？年齿耶？抑或面试言辞拙讷耶？投书多而回音寡。余于编码，素不敢怠，重代码之质，务求文义晓畅；设计 API，力求通用，以 [MDN][mdn] 为准则，不妄造规约。

前端之道，组件抽象为要，余于此颇有心得，惜不善言表。大要二端：其一，API 须有定规，浅显易晓；其二，一组件专任一事，毋过为雕琢。然今诸多开源库，多犯此二弊。

余性懒，少恒耐，今三十有六。中土业界，于此岁之寻常开发者，多不相容。虽勤学之力不若少壮，然终日伏案，可六时不辍，竟得颈椎病之疾。

雅好码事，非独自撰，亦常览他人开源之作，叹其构思践行之能。顾诸多产品之界面、动效、交互，多有不堪者。余本心喜精巧华美之物，此殆好前端之本由。或产品唯重功用，样式芜杂；或堆砌动画，繁而无当，皆非余之所好。遇此佳作，辄星标之，暇时下载源码，手自改订，聊以自娱，未尝提 PR。深知世之项目，鲜重界面细节，此独余一己之好恶而已。

余近于论理：若 CSS 之色如何衍变，动画缓动函数何以合度，着色器撰作之理，滚动速率缓急相宜之法，皆尝究心。然研罢逾周，辄复遗忘，重阅方忆，自知仅得皮毛，半吊子之徒也。

今日常以 AI 辅写代码，复自审阅。若构思幽微，难以向 AI 尽述，则手自先书，再令AI据余代码提炼提示词，与 AI 相佐为用。

借 AI 之力，余可独完一产品，自前端、后端以迄部署，一人而毕。惜性惮烦，除JS之外，于他种编程语言，心有抵牾。腹中方略甚多，而躬行之力不足。

年愈长，欲学者愈繁：AIGC、AI 游戏、剪辑、三维建模，皆所心慕。然电脑器能有限。习 GDScript 于游戏，中道而废；AIGC 粗阅教程即止；三维建模尚未启卷，以设备不堪软件之重载也。

至今犹奔走觅职。上所叙，乃十二载从业始末，兼陈一己优劣，杂感附焉。欲求面试高级前端之岗，冀以此理，裁为应对之辞。

我从事软件开发 12 年，头 2 年做 JavaWeb，之后转型专职前端。这 12 年里，项目大多是后台 Admin 系统，期间也做过数据可视化、微信小程序开发，后来还接触了 Electron 客户端开发。

学习 JavaWeb 阶段，我开始接触 SQL；折腾部署时，先后了解了 Tomcat、Nginx、Docker，但都只是会基础使用。

我一共待过 4 家公司，分别覆盖金融、交通、水利、医疗行业。各个领域业务差异巨大，但落到技术底层，我发现共性很强：依旧是后台管理、数据可视化、微信小程序这类场景。等到这类业务对我不再有难度，我便开始钻研项目模板。带我入门的是 [vue-element-admin][vea]，我花大量时间研读它的源码和文档，也正是通过它，我搭建起对前端工程化体系的完整认知。

之后我的前端技术提升很快，不再局限于页面开发和模板套用，开始研究**用代码生成代码**。那时候 “低代码” 这个名词还没普及，最开始我尝试用 VBA，发现它只能局限在 Office 生态，之后便改用 Node.js 持续试验；但慢慢意识到，JS 在性能层面并不适合这类场景。

于是我开始尝试学习新语言：从熟悉的 Java 入手，接着接触 Go、Python、C#、C++。对比下来，我觉得相比 JS，其他语言写起来更为繁琐，虽然它们的类型校验、约束更严谨。我也曾萌生过自研编程语言的想法，不过仅仅停留在构想阶段。后来 Rust 出现，所有权、生命周期这些新概念吸引了我，在我看来本质还是内存与指针管理，和 C 语言思路相近。我认清自己并非天才，学习 Rust 的过程中屡屡受挫，最后暂时搁置。后续打算潜心学习 Go、Python，往往看懂基础语法之后就很难继续深入，目前只能读懂这几门语言的基础语法。

不过 AI 兴起之后，即便没法达到资深开发者的水平，借助 AI，我也能用这些语言完成业务层面的开发。

后来受 AI 行业冲击，我遭遇裁员。待业期间一边找工作一边折腾技术，但收效一般。虽然多年做前端，对外说可以做全栈，但我自己心里其实没有十足把握。那段求职状态不算积极，做事拖拖拉拉，一晃快半年了。回想以前求职很快就能拿到 offer，现在处境一言难尽。

长期沉浸在自己的技术世界里，这次求职的落差对我打击不小。我也一直在思考问题到底在哪：是技术储备不足？简历呈现不好？年龄因素？还是面试表达能力偏弱？投递之后响应寥寥。代码层面我一直保持勤奋，十分看重代码质量，坚持代码逻辑清晰易懂；设计 API 时尽量追求通用性，参考 [MDN][mdn] 规范，不随意自定义设计。

前端里组件抽象是重中之重，我在这块积累了不少心得，只是不太擅长对外表达。简单来说两点：第一，API 设计需要统一规范，做到直观易懂；第二，单一组件只负责一件事，避免过度设计。但很多开源库恰恰存在这两类问题。

我本身偏懒，耐心有限，加上已经 36 岁。国内环境对于这个年龄段的普通开发并不友好。虽然学习精力不如年轻时，但我依旧可以连续在电脑前工作 6 小时，也落下了颈椎病这个职业病。

我喜欢折腾代码，不仅是自己写，也经常研读别人的开源项目，感叹创作者的思路与执行力。但很多产品的界面、动画、交互会让我难以接受。我骨子里偏爱精致酷炫的实现，这大概也是我深耕前端的根本原因。很多项目只实现功能，样式写得杂乱；也有不少项目堆砌过多动画，同样不符合我的审美。遇到这类项目，我会先 Star，有空拉取源码自行调整优化，但仅作为自娱自乐，不会提交 PR。我清楚大部分项目并不重视界面细节，这只是我个人审美偏好。

我算是偏理论型的开发者：比如 CSS 色彩体系如何衍生色值、动画函数怎么调节更自然、着色器编写思路、滚动速度如何把控得恰到好处。我会抽时间研究这类细节，但常常一周之后就遗忘，需要重新拾起来，也认清了自己属于半吊子的状态。

现在日常开发，我会借助 AI 写代码，再自行审查校验。遇到难以向 AI 描述清楚的想法，就先手写实现，再让 AI 参考我的代码提炼对应的 Prompt/Skill，形成和 AI 协作的模式。

依托 AI，我有能力独立完成从前端、后端再到部署的完整产品开发，做一人项目。但我本身比较惰性，除 JS 之外，对其他编程语言会本能排斥，想法很多，落地执行的动力不足。

年纪越大，想学习的方向就越多：AIGC、AI 游戏、视频剪辑、3D 建模都感兴趣。但电脑硬件配置有限。游戏方向学了 GDScript，最后半途而废；AIGC 只看了基础教程就搁置；3D 建模还没起步，软件跑不动。

目前仍在求职。上面是我 12 年的工作经历、个人优缺点和一些感慨，想请你帮我梳理，用于面试**高级前端工程师**岗位，提炼合适的自我介绍表述。

:::details ✍️ 原文

我从事软件开发 12 年，头 2 年是做的 JavaWeb，后来转型专职做前端。这 12 年里，基本都是 Admin 系统，中间也有数据可视化和微信小程序的开发，后来又流行 electron 的客户端开发。

在学习 JavaWeb 的时候，我开始学习了 SQL，中间在玩部署的时候接触了 Tomcat，再后来又接触了 Nginx，Docker，但是基本只能说会用。

我一共经历了 4 家公司，分别是金融，交通，水利和医疗行业，业务上肯定是天壤之别，但是到了底层我发现并没有太大的区别，依旧是后台管理，数据可视化，微信小程序。

后来我逐渐感觉这些业务对我来说没有太大的难处，我就开始研究那些项目模版，带我入门的是 vue-element-admin，无论源码还是文档，我都花了大量的时间去学习，因为它，我知道了前端的工程化体系如何去做。

而后我的前端技术突飞猛进，我不再局限于界面和模版，我开始研究如何利用语言来生成语言，后来我知道这就是低代码平台，那时候还没有这个词，一开始我用的是 VBA，而后发现其局限于 office，然后转而一直使用 Node 进行尝试，后来发现也许 JS 在性能上并不适合做这些。

我开始寻找新的计算机语言学习，从我最熟悉的 Java，随后是 Go，Python，C#，C++，但是了解后发现，其它的语言相比 JS 真的很啰嗦，也许这些语言很严谨吧，我也想过创造一个语言，但也就想想。后来出现一个颠覆性的语言：Rust，它推出了所有权和生命周期这类新概念，说实在也就是新概念，本质上对我而言依旧是如何管理指针和内存，和 C 差不多。我发现自己并不是一个天才，所以在学习 Rust 的时候真的也被劝退了，后来我想潜心研究下 Go，Python，发现基本在了解语法之后就没耐心去学习，导致我现在基本只能看懂以上计算机语言的基础语法。

但是 AI 出来，我发现我依旧可以去写这些语言，虽然没有真正的大佬们强，但是勉强开发业务是没问题的。

后来被 AI 冲击，我被裁员了，中间边找工作边折腾技术，收效甚微。因为这么多年都是在做前端，虽然我说我会全栈，但是我心里也没底。期间在找工作，不是积极应对，拖拖拉拉至今快半年了，很怀念以前找工作真的很快，现在一言难尽。

太久沉溺在个人世界，这次找工作对我的打击还是蛮大的，也不知道是我技术问题，还是我简历不行，还是我年纪问题，更或者是我口才不行？，反正没几个公司愿意要我，我自认为自己在代码上还算勤奋，因为我十分重视代码的质量，一直要求自己代码要做到通俗易懂，API 设计上也要尽可能通用，我尽可能参考的是 [MDN][mdn]，不是像一些库那样随意设计。

在前端比较重要的就是抽象组件，我对这块的心得很多，奈何不知道像外表达，不过大致上我是知道的，一：我前面提到的 API 设计要有一个标准，通俗易懂；二：一个组件就做一个事情，不必过度的设计。但是其实很多库依旧有着俩个最大的问题。

我很懒，也没有耐心，加上年纪已经来到了 36 岁，国内对这个年纪，特别是普通开发不是很友好，虽然在学习上的确没有年轻时那么有劲，但是我依旧可以在电脑前坐上 6 个小时，就这样还得了个职业颈椎病。

我喜欢折腾代码，不仅仅是自己写，更多是看别人的产品，感慨他们的想法，他们的行动力，不过有时候我真的受不了一些产品的界面，动画，交互。

我发现我骨子里还是很喜欢酷炫的东西，这也许也是我喜欢前端的真正原因。也因此，我发现很多产品的样式写的一团糟，只注重功能，忽律了界面，亦或是过度的动画界面堆砌，也让我受不了，偶尔我会先 Star 下来，然后得空去修改那些代码，当然也就自娱自乐，我是不会去提交 PR 的，因为没多少产品在乎界面，当然我也知道那是我的个人审美。

我发现自己还是个理论派，就像 CSS 中的一种色彩如何衍生其它色彩，动画函数如何设置更为合理，着色器优势如何去写，滚动条如何滚动才算不快不慢……。偶尔我也会花时间研究，但几乎一周也就忘了，后面又要重新研究下，也是让我知道自己就是个半吊子。

现在我日常就是使用 AI 来写代码，然后来检查，有时候实在不知道如何和 AI 描述我的想法，干脆我就自己手写，然后让 AI 参考我写的代码在总结出 Skill，也算和 AI 相辅相成了。

我感觉自己现在可以做一人产品，就是借助 AI 从前到后到部署都是我，但是我这个人懒，除了 JS，对其它的计算机语言，我能清晰地感觉到，有些排斥学习它们，导致我就是光有想法，没有行动能力。

我发现年纪越大想学的东西越多，从 AIGC，AI 游戏，剪辑，3D 建模我都想学习，但是我的这台电脑配置不行，导致我在游戏上学习了 GDScript，然后不了了之，AIGC 看了下教程就放弃了，建模压根没开始，因为我的电脑实在带不动软件。

我现在依旧在找工作，就像现在我说了一通，就是为了让你来帮我总结写，如果我要面试【高级前端工程师】那么我应该如何描述我的优势。

我这里面包含了我 12 年的工作的经验总结和个人的优缺点，也有我的牢骚，所以你帮我整理下，我自己实在不知道如何总结，我发现这块真是我的薄弱项。
